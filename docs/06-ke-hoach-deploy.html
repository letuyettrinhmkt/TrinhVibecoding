06 · Kế hoạch deploy

Đưa game lên Google Cloud

Chạy đúng bộ Docker Compose hiện có trên một máy ảo Compute Engine e2-micro thuộc gói miễn phí (Free Tier), phục vụ qua tên miền https://catxe.io.vn. Đây là bản kế hoạch: chưa có lệnh nào được chạy, chưa tạo tài nguyên nào.

Trước khi bắt đầu: giá và hạn mức Free Tier do Google thay đổi theo thời gian. Mọi con số dưới đây cần được đối chiếu lại với trang Free Tier của Compute Engine và bảng giá mạng vào ngày deploy. Chỗ nào chưa chắc chắn được đánh dấu cần xác nhận.

1. Sơ đồ

Toàn bộ hệ thống nằm trong một máy ảo. Bên ngoài chỉ thấy cổng 80 và 443; app (3000) và database (5432) chỉ nói chuyện với nhau trong mạng nội bộ của Docker.

Vì sao chọn cách này

  • Không phải sửa code game: dùng lại Dockerfile và docker-compose.yml đã chạy ổn trên máy local.
  • Caddy là reverse proxy nhỏ (vài chục MB RAM), tự xin và gia hạn chứng chỉ Let's Encrypt miễn phí cho catxe.io.vn. Không cần Load Balancer của Google (có tính phí).
  • Không dùng Cloud SQL: Cloud SQL không có trong Free Tier. PostgreSQL chạy trong container trên chính máy ảo.

3. Máy chỉ có 1 GB RAM

Debian + Docker đã chiếm khoảng 250–300 MB. Nếu không giới hạn, PostgreSQL và lúc build image Node có thể đẩy máy vào tình trạng hết RAM, Linux sẽ giết tiến trình ngẫu nhiên (OOM killer).

Thêm 2 GB swap

Swap là file trên đĩa dùng như RAM dự phòng. Chậm hơn RAM nhiều, nhưng giúp máy không sập khi bị dồn tải ngắn (ví dụ lúc docker compose build). Swap nằm trong 30 GB đĩa, không phát sinh chi phí.

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
# Chỉ dùng swap khi thật cần
echo 'vm.swappiness=10' | sudo tee /etc/sysctl.d/99-swap.conf
sudo sysctl --system

Phần ghép đè trong docker-compose.prod.yml (bản phác thảo):

services:
  db:
    mem_limit: 256m
    command: ["postgres", "-c", "shared_buffers=32MB", "-c", "work_mem=2MB",
              "-c", "max_connections=20"]
    logging: { driver: json-file, options: { max-size: "10m", max-file: "3" } }
  app:
    ports: !reset []          # không mở 3000 ra ngoài, chỉ Caddy gọi vào
    mem_limit: 192m
    environment:
      NODE_OPTIONS: "--max-old-space-size=128"
      TRUST_PROXY: "true"
    logging: { driver: json-file, options: { max-size: "10m", max-file: "3" } }
  caddy:
    image: caddy:2-alpine
    depends_on: [app]
    ports: ["80:80", "443:443"]
    volumes: ["./deploy/Caddyfile:/etc/caddy/Caddyfile:ro", "caddy-data:/data"]
    mem_limit: 64m
    restart: unless-stopped

4. Các bước deploy và cách kiểm tra

Làm lần lượt, bước trước đạt mới sang bước sau. Lệnh gcloud chạy trên máy cá nhân (cần cài Google Cloud CLI) hoặc trong Cloud Shell trên trình duyệt (không cần cài). Lệnh trên máy ảo chạy qua SSH.

BướcLàm gìKiểm tra đạt khi
D-01Đăng nhập và tạo project riêng cho game, ví dụ catxe-game. Liên kết tài khoản thanh toán (bắt buộc kể cả khi dùng Free Tier). Bật Compute Engine API.
gcloud projects create catxe-game
gcloud config set project catxe-game
gcloud billing projects link catxe-game --billing-account=XXXXXX-XXXXXX-XXXXXX
gcloud services enable compute.googleapis.com		gcloud billing projects describe catxe-game trả về billingEnabled: true.
D-02Đặt cảnh báo ngân sách 1 USD/tháng cho project, báo email ở 50%, 90%, 100% (Console → Billing → Budgets & alerts).Thấy budget trong danh sách. Lưu ý: budget chỉ gửi cảnh báo, không tự chặn chi tiêu.
D-03Giữ IP tĩnh
gcloud compute addresses create catxe-ip --region=us-central1		gcloud compute addresses list có catxe-ip, trạng thái RESERVED. Ghi lại địa chỉ IP.
D-04Tường lửa: mở 80/443 cho máy có tag web; SSH chỉ từ dải IAP; xoá luật mặc định mở 22 và 3389 cho cả Internet.
gcloud compute firewall-rules create allow-web --allow=tcp:80,tcp:443 --target-tags=web
gcloud compute firewall-rules create allow-ssh-iap --allow=tcp:22 --source-ranges=35.235.240.0/20
gcloud compute firewall-rules delete default-allow-ssh default-allow-rdp		gcloud compute firewall-rules list chỉ còn: allow-web, allow-ssh-iap, default-allow-icmp, default-allow-internal.
D-05Tạo máy ảo
gcloud compute instances create catxe-vm --zone=us-central1-a --machine-type=e2-micro --image-family=debian-12 --image-project=debian-cloud --boot-disk-size=30GB --boot-disk-type=pd-standard --address=catxe-ip --tags=web --metadata=enable-oslogin=TRUE --no-service-account --no-scopes		gcloud compute instances describe catxe-vm --zone=us-central1-a: machineType kết thúc bằng e2-micro, status: RUNNING. Trong Console → Disks: loại Standard persistent disk, 30 GB.
D-06SSH vào máy
gcloud compute ssh catxe-vm --zone=us-central1-a --tunnel-through-iap
Cập nhật hệ điều hành và bật tự cập nhật bảo mật: sudo apt update && sudo apt -y upgrade && sudo apt -y install unattended-upgrades git		Vào được dấu nhắc lệnh của máy ảo. Thử SSH thẳng không qua IAP phải bị chặn (hết thời gian chờ).
D-07Thêm 2 GB swap theo mục 3.free -h hiện Swap: 2.0Gi. Khởi động lại máy, kiểm tra lại vẫn còn.
D-08Cài Docker từ kho apt chính thức của Docker cho Debian (gồm docker-compose-plugin), thêm user vào nhóm docker.docker compose version ≥ 2.24 (cần cho !reset). docker run --rm hello-world chạy được.
D-09Trỏ tên miền: tại trang quản lý DNS của nhà đăng ký .vn, tạo bản ghi A catxe.io.vn → IP tĩnh và CNAME www → catxe.io.vn, TTL 300. Làm trước bước D-11 để Caddy xin được chứng chỉ.nslookup catxe.io.vn 8.8.8.8 trả đúng IP tĩnh (có thể chờ vài phút đến vài giờ).
D-10Lấy code và tạo .env
git clone https://github.com/letuyettrinhmkt/TrinhVibecoding.git catxe && cd catxe
Tạo .env từ .env.example bằng nano, sinh mật khẩu mới bằng openssl rand -hex 24 (không dùng lại mật khẩu ở máy local), TRUST_PROXY=true. Sau đó chmod 600 .env.		docker compose -f docker-compose.yml -f docker-compose.prod.yml config chạy không lỗi; app không còn mục ports; ls -l .env hiện -rw-------.
D-11Build và chạy
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build		docker compose ... ps: db và app healthy, caddy Up. docker stats --no-stream: mỗi container dưới giới hạn RAM. docker compose logs caddy có dòng chứng chỉ đã cấp cho catxe.io.vn.
D-12Kiểm tra từ máy cá nhân
  • https://catxe.io.vn mở được game, có ổ khoá HTTPS.
  • http://catxe.io.vn tự chuyển sang HTTPS.
  • https://catxe.io.vn/api/health trả {"ok":true}.
  • Đăng ký, chơi 1 lượt, điểm hiện trong /admin/.
  • http://IP:3000 và cổng 5432 không kết nối được.
  • Thử trên điện thoại dùng 4G.
D-13Sao lưu: đặt cron chạy bash deploy/backup.sh lúc 3 giờ sáng (dòng cron mẫu có sẵn ở đầu file). Định kỳ tải bản sao lưu về máy bằng gcloud compute scp --tunnel-through-iap.Sáng hôm sau có file trong ~/backups; thử khôi phục vào một database tạm trên máy local.
D-14Soát chi phí sau 24–48 giờ: Console → Billing → Reports, lọc theo project, nhóm theo SKU.Tổng chi phí 0 đ (nếu có tín dụng dùng thử, xem cột trước khi trừ tín dụng). Có dòng nào khác 0 thì xử lý theo mục 5.

Cập nhật phiên bản game sau này: SSH vào máy → cd catxe && git pull → chạy lại lệnh ở D-11 → kiểm tra lại D-12. Dữ liệu người chơi nằm trong volume nên không mất khi build lại.

Xoá sạch sau khoá học

  1. Lấy dữ liệu về (nếu cần): chạy deploy/backup.sh lần cuối và tải file về máy. Bản này có email, số điện thoại người chơi — lưu nơi an toàn hoặc xoá hẳn nếu không còn mục đích sử dụng.
  2. Gỡ DNS: xoá bản ghi A và CNAME www của catxe.io.vn ở nhà đăng ký, tránh tên miền trỏ vào một IP sau này có thể thuộc về người khác.
  3. Xoá cả project (cách sạch nhất, dừng mọi chi phí, xoá máy, đĩa, IP, tường lửa cùng lúc):
    gcloud projects delete catxe-game
    Project ở trạng thái chờ xoá 30 ngày rồi mới mất hẳn; trong thời gian đó không phát sinh phí.
  4. Kiểm tra: gcloud projects list không còn catxe-game (hoặc hiện DELETE_REQUESTED). Tuần sau xem Billing Reports không còn dòng nào của project.
  5. Tuỳ chọn: nếu không dùng Google Cloud nữa, đóng tài khoản thanh toán (Billing → Account management → Close billing account).

Điều kiện để bắt đầu deploy

  • Đã duyệt bản kế hoạch này.
  • Đã cài Google Cloud CLI hoặc sẽ dùng Cloud Shell; đã có tài khoản thanh toán.
  • Có quyền sửa DNS của catxe.io.vn.
  • Đã thêm các file ở mục 1 và khoá đăng nhập admin, test lại trên local xong 18/11/2026.
  • Đã xác nhận khoản phí IPv4 (mục 5).
