Đập Chuột

Mini game phản xạ trên trình duyệt: 30 giây, lưới 3×3, đập trúng càng nhiều chuột càng tốt.

01 Tổng quan Mục tiêu, người dùng, phạm vi, thuật ngữ và 5 quyết định đã chốt khi phỏng vấn. Đọc → 02 Chức năng 13 chức năng F-01 → F-13: đếm ngược, đồng hồ, chuột, đập, tạm dừng, kỷ lục, chơi lại. Đọc → 03 Màn hình Luồng màn hình, wireframe khổ điện thoại, đặc tả thành phần theo token, chuyển động. Đọc → 04 Quy tắc & dữ liệu Hằng số, máy trạng thái, quy tắc R-01 → R-18, mô hình dữ liệu, localStorage, tình huống biên. Đọc → 05 Kế hoạch test 29 ca test chức năng, 9 ca giao diện, cách đo đồng hồ và tiêu chí hoàn thành. Đọc → 06 Kế hoạch deploy Đưa game lên Google Cloud Free Tier (e2-micro) với tên miền catxe.io.vn: sơ đồ, các bước, chi phí, bảo mật. Đọc →

Tóm tắt nhanh

Luật

Đập trúng +1, trượt 0, mỗi chuột tính một lần.

Mới sau phỏng vấn

Đếm ngược 3-2-1, tự tạm dừng khi rời tab, thống kê chính xác, nút "Về trang chủ".

Hình ảnh

Chuột SVG tông hồng, theo design/tokens.css.

Kỹ thuật

HTML + CSS + JS thuần, chạy offline, responsive từ 360 px.

Nguồn yêu cầu: YEU-CAU.md. Bộ tài liệu này chưa bao gồm code game.
